# FACE RECOGNITION

## How to run

1. Ensure you have python installed. Recommended version 3.13
2. Clone the [Repository](https://github.com/Germanium-Jeremy/FaceRecognition.git)
3. Create a virtual environment
```bash
python3 -m venv .venv
```
4. Activate the virtual environment
```bash
.venv/Scripts/avctivate
```
Or on linux or mac
```bash
source .venv/bin/activate
```
5. Install the required dependencies
```bash
pip install -r requirements.txt
```
6. The running process is similar to the one in the provided document
